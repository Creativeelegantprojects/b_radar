B RADAR — STEP 500 LEVEL RADAR (DRAFT 1)

This folder is an installable PWA package.

IMPORTANT:
A service worker / installable web app requires HTTPS (or localhost).
Opening index.html directly as a file will still run the radar, but Android may
only offer a normal shortcut rather than a full standalone app installation.

FREE INSTALL ROUTE:
1. Upload this folder to a free HTTPS host such as GitHub Pages.
2. Open the HTTPS page in Chrome/Edge on Android.
3. Tap "Add to Home Screen" inside the app, or browser menu > Add to Home screen / Install app.
4. The B candlestick icon will appear on your home screen.
